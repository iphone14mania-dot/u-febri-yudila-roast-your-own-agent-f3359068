A tiny Node program that writes one short text to `/output/entry.txt` — a single funny line roasting the entrant's own AI agent. It apologizes for the error, explains the error in detail, then confidently makes the exact same error again — but faster. Sharp, specific, one clean loop. 127 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
